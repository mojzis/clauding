Use only these tags. Add new ones here, in the same change, with a one-line meaning.

- `meta`: about the docs themselves
- `domain`: business concepts and rules
- `architecture`: structure, boundaries, data flow
- `ops`: deploy, config, runtime, infra
- `dev`: local setup, tooling, CI
- `qa`: tests, checks, oracles, what "correct" means
